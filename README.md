# 🏠 DreamHome - Real Estate Website

DreamHome is a modern real-estate website that allows users to explore properties, search for properties, register/login, and manage their profile.

The project includes a responsive frontend and a Node.js backend API for user authentication and profile management.

---

## 🚀 Features

### 🏡 Home Page
- Modern real-estate landing page
- Property search
- Featured properties
- About section
- Contact section
- Responsive navigation

### 🔍 Property Search
- Search properties based on different criteria
- Property listing page
- Property details
- Responsive property cards

### 👤 User Authentication
- User registration
- User login
- User logout
- Profile page
- User information display
- Authentication using backend API

### 📱 Responsive Design
- Desktop friendly
- Tablet friendly
- Mobile friendly
